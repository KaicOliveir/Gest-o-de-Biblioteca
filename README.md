Sistema de Gerenciamento de Livros

Este projeto foi desenvolvido em Python com o objetivo de criar um sistema simples para gerenciamento de livros de uma biblioteca. Durante o desenvolvimento, utilizamos conceitos de programação orientada a objetos, listas, funções, estruturas de repetição e condicionais.

O sistema permite cadastrar livros informando título, autor, gênero e quantidade disponível. Também é possível listar os livros cadastrados, realizar uma busca pelo título e visualizar um gráfico com a quantidade de livros por gênero, utilizando a biblioteca Matplotlib.

Com essa atividade foi possível colocar em prática os principais conceitos estudados em Python e entender melhor como organizar diferentes funcionalidades dentro de um programa.
